Build a production-grade, mobile-responsive E-Commerce Storefront web application for "Gebyian Network" (Pig Project Rwanda Marketplace) using Next.js (App Router), TypeScript, and Tailwind CSS that connects directly to and stays synchronized with the Pig Project Control Panel managed by Project Manager (Gebyian).

2. TWO-PART GEBYIAN NETWORK WORKFLOW & ACTIVE ROLES
======================================================================
Only the 7 active system roles operate across the Control Panel and Gebyian Network:
1. `SUPER_ADMIN` ("Super Administrator")
2. `PROJECT_MANAGER` ("Project Manager (Gebyian)")
3. `CELL_MANAGER` ("Cell Manager")
4. `COOPERATIVE_LEADER` ("Cooperative Leader")
5. `COOPERATIVE_MEMBER` ("Cooperative Member")
6. `VETERINARIAN` ("Veterinarian")
7. `FINANCE_OFFICER` ("Finance Officer")

Gebyian Network is divided into TWO clear operational parts sharing the same Supabase database:

PART A — ANIMALS MARKETPLACE (`store_section = 'ANIMALS'`, Live Pigs & Livestock Sold to Public Buyers):
1. Cooperative Stock Reporting by Cell Manager (`CELL_MANAGER`):
   - Whenever a `COOPERATIVE_LEADER` or `COOPERATIVE_MEMBER` has pigs ready to sell, the `CELL_MANAGER` submits a Cooperative Animal Stock Report (`cooperative_stock_reports`) from the Control Panel.
2. Pricing, Discounts & Stock Control by `Project Manager (Gebyian)` (`PROJECT_MANAGER`):
   - `Project Manager (Gebyian)` (with `SUPER_ADMIN` oversight) reviews cooperative stock reports, sets the official stock quantity, base RWF price, and active product discount (`discount_percent`, `discount_price`, `discount_label`, `discount_starts_at`, `discount_ends_at`), and publishes animals into `store_products` with `store_section = 'ANIMALS'`.
3. Public Buyer Cart, Checkout & Order Message to `Project Manager (Gebyian)`:
   - Public buyers browse Gebyian Network (`store_section = 'ANIMALS'`, `isAvailable = true`, `stock > 0`), add animals to their shopping cart, and submit their order.
   - Placing an order writes to `store_orders` + `store_order_items` (or calls `POST <CONTROL_PANEL_BASE_URL>/api/ecommerce/orders`) AND immediately sends an order notification message in `"Notification"` to `Project Manager (Gebyian)` (`PROJECT_MANAGER`) and `SUPER_ADMIN`.

PART B — ANIMAL FOOD & FEED SUPPLIES (`store_section = 'ANIMAL_FOOD'`):
1. Stock, Price & Discount Control by `Project Manager (Gebyian)`:
   - `Project Manager (Gebyian)` creates animal feed/supply products in `store_products` (`store_section = 'ANIMAL_FOOD'`) and sets their stock, RWF price, and optional discount.
2. Cell Manager Field Feed Sales:
   - `CELL_MANAGER` sells animal food/feed in their cell (`akagari`) using the stock and prices set by `Project Manager (Gebyian)`.
   - Every Cell Manager feed sale decrements `store_products.stock`, inserts into `cell_feed_sales`, and records a `SUBMITTED` `FinanceTransaction` (`"Animal Feed Sales"`).
3. Finance Officer Verification & Reports (`FINANCE_OFFICER`):
   - `FINANCE_OFFICER` reviews every Cell Manager animal food sale report inside the Control Panel Finance dashboard, verifies or rejects each transaction, and views full revenue & cell sales reports.

3. SHARED DATABASE & ENVIRONMENT VARIABLES (.env)
======================================================================
Connect to the SAME Supabase project used by the Pig Project Control Panel:
- SUPABASE_URL=<same SUPABASE_URL as Control Panel>
- SUPABASE_ANON_KEY=<same SUPABASE_ANON_KEY as Control Panel>
- SUPABASE_SERVICE_ROLE_KEY=<same SUPABASE_SERVICE_ROLE_KEY as Control Panel> (server-side ONLY, never NEXT_PUBLIC_)
- CONTROL_PANEL_BASE_URL=<URL of Pig Project Control Panel>
- ECOMMERCE_WEBHOOK_SECRET=<same secret as Control Panel>

Shared Supabase tables (kept in sync via Control Panel `db.sql` & `update.sql`):
1) `store_products`:
   - `id`, `name`, `description`, `price` NUMERIC(12,2), `discount_percent` NUMERIC(5,2) DEFAULT 0, `discount_price` NUMERIC(12,2), `discount_label` TEXT, `discount_starts_at` TIMESTAMP(3), `discount_ends_at` TIMESTAMP(3), `stock` INTEGER DEFAULT 0, `low_stock_threshold` INTEGER DEFAULT 3, `category` TEXT (`Livestock`, `Pork Products`, `Animal Feed`, `Supplements`, `Supplies`, `Training Guides`), `store_section` TEXT DEFAULT `'ANIMALS'` (`'ANIMALS'` | `'ANIMAL_FOOD'`), `imageUrl`, `isAvailable` BOOLEAN, `pig_id`, `source_pig_tag`, `createdAt`, `updatedAt`.
2) `store_orders`:
   - `id`, `order_number` (UNIQUE, "ORD-YYYY-XXXX"), `customer_name`, `customer_email`, `customer_phone`, `shipping_address`, `subtotal_amount` NUMERIC(12,2), `discount_total` NUMERIC(12,2) DEFAULT 0, `total_amount` NUMERIC(12,2), `status` ("PENDING" | "PAID" | "PROCESSING" | "DISPATCHED" | "COMPLETED" | "CANCELLED"), `payment_method`, `payment_reference`, `notes`, `created_at`, `updated_at`.
3) `store_order_items`:
   - `id`, `order_id`, `product_id`, `quantity`, `original_price` NUMERIC(12,2), `discount_amount` NUMERIC(12,2) DEFAULT 0, `price` NUMERIC(12,2) (discounted unit price paid).
4) `cooperative_stock_reports`:
   - Animal stock reported by Cell Manager (`reported_by_id`, `cooperative_owner_name`, `cooperative_owner_role`, `cell_name`, `animal_title`, `pig_count`, `estimated_weight_kg`, `suggested_price`, `pig_id`, `source_pig_tag`, `status` PENDING|LISTED|REJECTED, `listed_product_id`).
5) `cell_feed_sales`:
   - Animal food sales recorded by Cell Manager (`sale_number`, `product_id`, `product_name`, `buyer_name`, `buyer_phone`, `quantity`, `unit_price`, `total_amount`, `payment_method`, `sold_by_id`, `sold_by_name`, `cell_name`, `finance_transaction_id`, `verification_status` PENDING|VERIFIED|REJECTED).

4. STRICT STOCK & INVENTORY LOGIC (NO OVERSELLING)
======================================================================
1. Storefront Visibility:
   - Default catalog displays `store_section = 'ANIMALS'` (with a clear secondary tab/view for `ANIMAL_FOOD` showing Cell Manager distribution availability) where `isAvailable = true` and `stock > 0`.
   - Show stock badges: "In Stock", "Only X left!" (`stock <= low_stock_threshold`), or "Out of Stock".
   - Quantity pickers in product detail and cart MUST cap at live `product.stock`.
2. Live Re-Validation & Atomic Stock Deduction (`POST /api/orders`):
   - Re-fetch every cart item using `SUPABASE_SERVICE_ROLE_KEY` (or call `POST <CONTROL_PANEL_BASE_URL>/api/ecommerce/orders`).
   - Reject (`409 Conflict`) if `isAvailable === false`, `stock < requestedQuantity`, or if a `pig_id`-linked pig fails veterinary clearance.
   - Perform an atomic conditional stock decrement (`stock = stock - quantity` only when `stock >= quantity` and `isAvailable = true`); roll back on conflict.
   - When a `pig_id`-linked SKU hits `stock === 0`, mark `"Pig".status = 'SOLD'`.
   - Immediately insert `"Notification"` alerts for BOTH `Project Manager (Gebyian)` (`PROJECT_MANAGER`) and `SUPER_ADMIN` with order number, buyer contact, items, and total RWF.
3. Stock Restoration on Cancellation:
   - Cancelled orders restore `store_products.stock += item.quantity` and restore linked `"Pig".status = 'ACTIVE'`.

======================================================================
5. MANAGER-CONTROLLED PRODUCT DISCOUNT LOGIC
======================================================================
1. Effective Price Calculation Utility (`getEffectiveProductPrice(product, now)`):
   - Active check: `(discount_starts_at == null || now >= discount_starts_at)` AND `(discount_ends_at == null || now <= discount_ends_at)`.
   - If active and `discount_price > 0 && discount_price < price`: `effectivePrice = discount_price`, `discountPercent = Math.round(((price - discount_price) / price) * 100)`.
   - Else if active and `discount_percent > 0 && discount_percent <= 90`: `effectivePrice = Math.round(price * (1 - discount_percent / 100))`.
   - Otherwise: `effectivePrice = price`.
2. Storefront Display:
   - Show Amazon Orange (`#FF8A00`) discount badge (`-{percent}%` + optional `discount_label`), crossed-out original RWF price (`line-through`), bold discounted RWF price, and cart/checkout savings breakdown ("Original Subtotal", "Discount Savings", "Final Total").
   - Include an "On Sale / Discounted" filter chip in the catalog.
3. Server-Side Price Integrity:
   - `POST /api/orders` MUST compute `original_price`, `discount_amount`, final `price`, `discount_total`, and `total_amount` exclusively on the server from DB `store_products` and active discount windows—never trusting browser-submitted prices.

6. GEBYIAN NETWORK PAGES & API INTEGRATION
======================================================================
- `/` (Gebyian Network Catalog): Split cleanly with tabs for **Animals Marketplace** (`store_section = 'ANIMALS'`) and **Animal Food & Supplies** (`store_section = 'ANIMAL_FOOD'`, noting Cell Manager cell distribution or local pickup), plus search bar, "On Sale" toggle, category filters, `Vet-Cleared Tag` badge when `source_pig_tag` exists, discount badge, live stock badge, and Add to Cart for Animals.
- `/products/[id]` (Product Detail): Full photo, description, vet traceability badge, live stock count, active discount & expiry notice, quantity picker capped at `stock`, Add to Cart.
- `/cart` & `/checkout`: Persistent cart synced with live DB prices & stock, customer checkout form (`customerName`, `customerPhone` / `customerEmail`, `shippingAddress`, `paymentMethod`: MTN MoMo, Airtel Money, Bank Transfer, Cash on Delivery, `notes`). On submit, calls `POST <CONTROL_PANEL_BASE_URL>/api/ecommerce/orders` (or creates order in Supabase + notifies `Project Manager (Gebyian)` & `SUPER_ADMIN`).
- `/track` (Order Tracker): Lookup by `order_number` + phone/email showing real-time status (`PENDING` -> `PAID` -> `PROCESSING` -> `DISPATCHED` -> `COMPLETED` / `CANCELLED`), itemized receipt with discount savings, and payment confirmation status synced from `Project Manager (Gebyian)`.
- `/api/payments/callback`: Verifies payment amount against `store_orders.total_amount` and forwards `PAID` / `CANCELLED` webhooks to `POST <CONTROL_PANEL_BASE_URL>/api/ecommerce/webhooks/payment` with `x-webhook-secret`.
